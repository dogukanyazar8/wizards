## D3. Web paritesi — grup yönetimi (K5)

Web'e grup yönetimi eklenir. **Mobil handoff pikselleri kopyalanmaz** — mevcut web tasarım dili (`packages/ui`, mevcut ayar paneli deseni). Davranış ve kural kümesi mobil ile birebir aynı; ikisi de aynı uçları ve aynı `getGroupCapabilities` mantığını kullanır (kural `packages/types` içinde tek yerde).

Eklenecek yüzeyler:

1. **Grup bilgisi paneli** — kimlik (ad, açıklama, renk/ikon), üye listesi, rol çipleri, sabitlenmiş mesaj, medya sayacı.
2. **Grup ayarları** — bildirim kademesi, dört izin, davet bağlantısı (aç/kapa/kopyala/yenile), kaybolan mesajlar, sohbeti gizle, gruptan ayrıl (+ son yönetici devri).
3. **Üye eylemleri** — yönetici yap / yöneticiliği al / gruptan çıkar; yetkisiz eylem menüde **görünmez**.
4. **Sohbette** — gönderen adı rengi (`nameColor`), sabitlenmiş mesaj şeridi, okundu bilgisi, kaybolan mesaj göstergesi.

Kısıt: web'e **yeni bir tasarım dili** girmez, mobil token grubu web'e taşınmaz. Testler mevcut web test desenine (DI'lı `route-logic` + bileşen testi) uyar.

## J. Rapor + cihaz test listesi

`raporlar/05-rapor.md` + `raporlar/00-paket-kapanis.md` (30 kriterin tablo hâlinde sonucu).

Cihaz testi (kullanıcı koşar) en az:

1. İki cihazdan aynı gruba yaz → gönderen adı/rengi doğru, ardışık balonda ad tekrar etmiyor.
2. Bir cihazda oku → diğerinde okundu yığını ve `n kişi okudu` güncelleniyor; herkes okuyunca `Herkes okudu`.
3. Mesaj sabitle → iki cihazda şerit çıkıyor; birinde çarpıya bas → yalnız orada gizleniyor.
4. `@` yazıp üye seç → pil doğru renkte; karşı tarafta `@N` rozeti düşüyor.
5. Bildirimi `Yalnız bahsetmeler` yap → normal mesajda bildirim yok, bahsetmede var.
6. İzni `Yalnız yöneticiler` yap → normal üyede composer kapanıyor, API isteği 403.
