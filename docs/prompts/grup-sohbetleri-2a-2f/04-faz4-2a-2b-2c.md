## E. 2c — Yeni grup, grup bilgileri

Dosya: `screens/group-create/identity-step.tsx`.

### E1 — Katmanlar (HTML 213–269)

1. Başlık: geri + `Grup bilgileri` + `Adım 2 / 2 · 3 üye seçildi`; **iki çubuk da dolu**.
2. Kimlik satırı: 72/r24 avatar (grup adının baş harfleri, seçili renk zemini, 24/800 beyaz) + sağ altta 28/r10 beyaz kamera düğmesi; yanında `GRUP RENGİ` + beş 28/r10 kare (`#4F46E5`, `#1B8A55`, `#C77A2B`, `#C2185B`, `#1E2235`), seçilide `0 0 0 2px <zemin>, 0 0 0 4px <renk>` çift halka.
3. `GRUP ADI` + `18/32` sayacı; h48/r15 beyaz alan, odakta 1.5px `#4F46E5` + `0 0 0 3px rgba(79,70,229,.12)`, metin 15/700.
4. Ad boşsa ipucu: 13px bilgi ikonu + `Boş bırakırsan grup adı **Atakan, UAT Test ve DY** olur` (`buildGroupNameHint`, canlı).
5. `AÇIKLAMA — isteğe bağlı` + `0/120`; h62/r15 `#ECEEF7` alan.
6. `ÜYELER 3` + `Düzenle` (12/800 indigo → 1. adıma döner, seçim korunur); 46/r16 avatar şeridi, ilk kutu **Sen** (10.5/700 indigo etiket), son kutu kesikli `Ekle`.
7. `KATILIM` kartı: `Üye ekleyebilir — Herkes` (chevron), `Davet bağlantısı — Bağlantısı olan katılabilir` (toggle **kapalı**), `Yeni üyeler geçmişi görür — Son 30 gün` (chevron).
8. Alt çubuk: h50/r16 indigo `Grubu oluştur`.

### E2 — Davranış

- Görsel yüklenirse renk şeridi yerini `Görseli kaldır` bağlantısına bırakır (§2c/2). Yükleme mevcut `group-icon-upload` yolundan.
- `KATILIM` kartındaki üç değer oluşturma isteğine gider: `permAddMembers`, davet bağlantısı `enabled`, `historyVisibility`. **Davet bağlantısı varsayılan kapalı** (K2) — açıkken oluşturulursa kod grup kurulur kurulmaz üretilir.
- Ad boş bırakılabilir; oluşturulan grubun adı ipucu metniyle **birebir aynı** olur (§4.4).
- Oluşunca 2d'ye geçilir ve sohbet listesinin en üstüne düşer (`lastMessageAt` = şimdi).
- Geri: 2. adımdan 1. adıma dönüş seçimi korur; 1. adımdan çıkış seçimi **sorar** (`Grup oluşturmaktan vazgeçilsin mi?`) yalnız en az bir seçim varsa.
