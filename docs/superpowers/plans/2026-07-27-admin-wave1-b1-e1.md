# Admin Dalga 1 — B1 Yetki Politikası + E1 Kampanya Gönderim Güvenliği

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Üretimdeki iki canlı hatayı kapat: (1) rol filtresiz admin API rotaları, (2) kampanya çift-gönderimi.

**Architecture:** B1 tek capability haritası (`lib/admin/capabilities.ts`) kurar; tüm admin rotaları oradan geçer, sözleşme testi kaçağı engeller. E1 kişi-bazlı `CampaignDelivery` kaydıyla gönderimi idempotent yapar; alıcı listesi bir kez dondurulur, yeniden deneme yalnızca `PENDING` satırları işler.

**Tech Stack:** Next.js App Router route handlers, Prisma 7 (migration dizini `packages/db/prisma/rebaseline-migrations` — başka dizin sessizce çalışmaz), zod, node test runner.

**Spec'ler:** `docs/superpowers/specs/2026-07-26-admin-panel-shell-design.md` §5 (B1), `docs/superpowers/specs/2026-07-26-admin-campaigns-product-voice-design.md` §E1.

**Interfaces:**

- Produces: `freezeCampaignRecipients(campaignId, now?): Promise<{ pending: number; skipped: number }>` — idempotent: `frozenAt` doluysa hiçbir şey yazmaz, mevcut sayıları döner.

- [ ] **Step 1: Kırmızı testler** (prisma mock/test-db, mevcut lib test desenini izle):
  1. İlk çağrı: segment çözülür, alıcı başına `PENDING` satır, `frozenAt` damgalanır.
  2. Frekans limiti: son 24 saatte 2 `SENT` `CampaignDelivery` kaydı olan kullanıcı `SKIPPED`+`FREQUENCY_CAP` yazılır (`MODERATION` tipi kampanya limitten muaf — kampanya `type` kontrolü).
  3. İkinci çağrı: satır sayısı değişmez (idempotent).
- [ ] **Step 2-4: Uygula, yeşil gör.** Çekirdek:

```ts
export async function freezeCampaignRecipients(campaignId: string, now = new Date()) {
  const campaign = await prisma.notificationCampaign.findUniqueOrThrow({
    where: { id: campaignId },
    select: { frozenAt: true, segment: true, type: true },
  });
  if (campaign.frozenAt) return countDeliveries(campaignId);
  const recipientIds = await getCampaignRecipientIds(
    normalizeCampaignSegment((campaign.segment as CampaignSegment | null) ?? { type: "ALL_USERS" }),
  );
  const capped =
    campaign.type === "MODERATION"
      ? new Set<string>()
      : await findFrequencyCappedUserIds(recipientIds, now);
  await prisma.$transaction([
    prisma.campaignDelivery.createMany({
      data: recipientIds.map((userId) => ({
        campaignId,
        userId,
        status: capped.has(userId) ? "SKIPPED" : "PENDING",
        ...(capped.has(userId) ? { skipReason: "FREQUENCY_CAP" } : {}),
      })),
      skipDuplicates: true,
    }),
    prisma.notificationCampaign.update({ where: { id: campaignId }, data: { frozenAt: now } }),
  ]);
  return countDeliveries(campaignId);
}
```
